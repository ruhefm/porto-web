# **Relate Project**


This is a group project called RELATE, primarily a server-side web application enable user to identify their device screen condition and gain recommendation through self trained Machine Learning. My main responsibility was integrating computer vision using YOLO (in Python) and displaying the results on the frontend. The project also features a chatbot built with React and NLP, which recommends appropriate actions based on the output—such as suggesting nearby repair shops if a phone screen is detected as cracked. The tech stack includes Python, Django, and UI-Kit for the frontend.
